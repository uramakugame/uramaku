# URAMAKU — November 12, 2026 build

Base: `uramaku-intrigue-card-selection-shared-layout.zip`

## Confirmed gameplay and localization changes

- The role name remains **Swordsman** in English. Its Japanese label is now **用心棒** (Yojinbo), replacing 浪人 (Ronin).
- English action and counter labels: **Tax**, **Hire Blade**, **Assassinate**, **Extort**, **Hire Guard**, **Enforce**, and **Intimidate**.
- Swordsman's Japanese counter is **護衛を雇う** (Hire Guard). Hire Blade is localized as **刺客を雇う**.
- **Hire Guard costs 3 coins, payable only when the counter claim succeeds** (not at declaration or when a bluff fails). Payment returns coins to Treasury in Treasury Mode.
- A player without 3 coins is not offered Hire Guard as a counter to Assassinate, even if they hold Swordsman.

## UI changes

- Game room and guided tutorial share the same revealed/hidden role-card renderer (`public/js/components/role-cards.js`) to avoid independent markup and styling.
- Guide tabs now read **Actions** / **How to Play**. The modal grows to content height when the viewport permits; it scrolls on compact screens.
- When responding to Intrigue, only compact decision buttons are shown. After paying 1 coin to hide one influence, choose the card on your own player card using the same overlay selection affordance as influence loss (**Hide this influence**).
- If only one eligible unknown influence remains, it is concealed automatically without a follow-up selection prompt.
- The game Actions panel uses a transparent background regardless of faction visibility or Treasury/Standard mode; removed an overriding dark-purple background from shared CSS.

## Verification

- `npm test` passes, including new coverage for paid Hire Guard, influence concealment, shared card markup and modal-height regression.
- `npm run test:economy-stress` passes: 280 randomized completed matches, no economy invariant violations.
- Playwright manual-style render check: shared tutorial cards render with no page errors; English reference content fits without vertical scrolling on 1600×1050 and 1440×900 viewports. Small mobile viewport scrolls when needed.

## Run

Install dependencies (`npm install`) in the `uramaku-browser` folder and start with `npm start`.
